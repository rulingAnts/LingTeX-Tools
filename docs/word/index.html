Beta LingTeX-Word 0.1.0-beta.6

Interlinear glossed text, right inside Microsoft Word

Copy an example from FLEx and click once. LingTeX-Word turns it into an aligned, numbered example that wraps to your page. After an edit it re-wraps when the cursor moves on, when you save, or at the click of Re-wrap All.

For Word 2016 or later and Microsoft 365, on Windows and Mac.

From FLEx to a finished example in three steps

Everything lives on one Interlinear tab. Your examples are ordinary Word tables in named styles, so the document opens and prints anywhere, even where LingTeX-Word is not installed.

1

Paste from FLEx

Select the interlinear text in FLEx, choose Edit › Copy, and click Insert Interlinear. The lines you show in FLEx’s interlinear view are the lines you get. An ordinary table and lines you typed convert too, with Convert Table and Text to Interlinear.

2

It wraps to the page

Columns flow onto the next line when the page runs out, and flow back when there is room. An example re-wraps when the cursor leaves it and when you save; after a margin change, Re-wrap All does the whole document at once.

3

Refine and check

Split or merge columns at morpheme breaks, align by word or by morpheme, and check the glossing against the Leipzig Glossing Rules.

Made for writing grammars

The details that take the longest by hand are the ones LingTeX-Word does for you.

Numbered by Word

(1), (2), (3)… use Word’s own list numbering, so moving or deleting an example renumbers the rest.

By word or by morpheme

One column per word, with clitics kept in their host’s column, or one column per morpheme.

Small-capital glosses

Grammatical glosses such as ERG and 3SG are recognised by their shape and set in small capitals, with or without a full-size first capital.

Check Glossing

Finds morpheme breaks that don’t line up, spaces inside cells and unmatched infix brackets, and repairs what has one right answer.

Your spacing, your styles

Set spacing and padding in points or as a share of the font size, and adjust every example style with Word’s own style dialog.

Keyboard shortcuts

Every command has one: Ctrl+Alt+Shift and a letter on Windows, Cmd+Option+Shift on Mac. A key Word already uses is never taken.

Install in a minute

Close Word first. Upgrading works the same way: the new version replaces the old one, and your documents keep working.

🪟 Windows

  1. Download and run the installer.
  2. It isn’t signed yet, so Windows may say “unknown publisher”: choose More info, then Run anyway.
  3. Start Word. A message lists your keyboard shortcuts, and the Interlinear tab is on the ribbon.

To remove it: Settings › Apps › LingTeX-Word › Uninstall.

⬇ Windows installer Zip

Mac

  1. Open the disk image and double-click Install LingTeX-Word.
  2. It opens in Script Editor with what it does written at the top. Click Run (▶). If macOS asks whether Script Editor may access data from other apps, click Allow.
  3. Start Word and choose Enable Macros. The Interlinear tab is on the ribbon.

To remove it: run Uninstall LingTeX-Word from the disk image the same way.

⬇ Mac disk image

LingTeX-Word is in beta. It is tested by hand on Windows and Mac, and it will still have rough edges. The user guide covers every command; if something breaks, please tell us.
