Microsoft Word

LingTeX-Word Beta

An Interlinear tab in Microsoft Word. Paste from FLEx and get an aligned, numbered example that wraps to your page and re-wraps as you edit.

  • Paste from FLEx, convert a table, or type the lines
  • Re-wraps to the page; split and merge columns in place
  • Small-capital glosses and Word’s own numbering

LaTeX & XLingPaper

Desktop app & extension

A menu-bar and tray app, a browser extension and a web converter that turn FLEx interlinear text and Phonology Assistant exports into LaTeX, tab-separated tables and, soon, XLingPaper.

  • Keyboard shortcuts that work in any editor, Overleaf included
  • An app for macOS and Windows; an extension for Chrome and Firefox
  • Nothing to install to try it: convert in your browser
