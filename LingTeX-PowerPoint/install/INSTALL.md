# Installing LingTeX-PowerPoint

LingTeX-PowerPoint is one file, `LingTeX-PowerPoint.ppam`, a PowerPoint add-in
that puts an **Interlinear** tab on the ribbon.

## Mac

Quit PowerPoint. Double-click **Install LingTeX-PowerPoint** (a script document;
what it does is written at the top) and press **Run**. It copies the add-in
into PowerPoint's Startup folder:

    ~/Library/Group Containers/UBF8T346G9.Office/User Content/Startup/PowerPoint

Start PowerPoint; choose **Enable Macros** if asked. **Uninstall
LingTeX-PowerPoint** removes it the same way. Upgrading is running the install
again: the old file is replaced.

## Windows

Not yet packaged. By hand: PowerPoint > File > Options > Add-ins > Manage:
PowerPoint Add-ins > Go > Add New, and choose `LingTeX-PowerPoint.ppam`.
